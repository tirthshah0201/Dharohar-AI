## Backend Changes

### Chatbot: `backend/src/services/chatbot.ts`

**New intent:** `explore_collection`

Added collection discovery to the chatbot:

- **Intent detection:** Recognizes collection-related queries ("show me crafts", "first time explorer", "natural heritage", etc.)
- **Collection matching:** Maps user queries to collections using keyword-based scoring
- **Keywords per collection:**
  - Sacred Architecture: temple, fort, palace, stepwell, monument, architecture
  - Indian Crafts: craft, handicraft, weaving, embroidery, pottery, artisan
  - Living Traditions: tradition, festival, food, cultural, community
  - Natural Heritage: natural, waterfall, wildlife, beach, mountain, river
  - Ancient India: ancient, classical, early, indus, chola, kalinga
  - First-Time Explorer's Guide: first time, beginner, must see, essential, famous
- **Response:** Returns matching collection with description and entity count
- **Fallback:** Lists all collections when no specific match
- **Action:** Adds `explore_collection` action to chatbot responses

### Collections API: `backend/src/routes/collections.ts`

**New endpoint:** `GET /api/collections/:slug/related`

Returns related collections based on shared heritage entities. Useful for discovery flow.

### Search API: `backend/src/routes/search.ts`

**Improved ranking:** Three-tier relevance scoring:

| Score | Match Type |
|-------|-----------|
| 1.0 | Exact name match |
| 0.9 | Name starts with query |
| 0.7 | Name contains query |
| 0.4 | Description contains query |
| 0.3 | Description starts with query |

**Collection suggestions:** Search suggestions now include matching collections alongside heritage, states, periods, and categories.
