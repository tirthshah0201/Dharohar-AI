## Database Changes

### Migration 004: `004_p1_canonical_ids.sql`

**Purpose:** Add canonical slug columns to locations and heritage_entities

**Schema Changes:**
```sql
-- New columns
locations.slug VARCHAR(255) UNIQUE
heritage_entities.slug VARCHAR(255) UNIQUE

-- New indexes
idx_locations_slug ON locations(slug)
idx_heritage_slug ON heritage_entities(slug)

-- New function
generate_slug(input_text TEXT) → TEXT
```

**Data Changes:**
- All existing locations get slugs generated from their names
- All existing heritage_entities get slugs generated from their names
- Duplicate slugs are disambiguated

**Safety:**
- ✅ Non-destructive (ADD COLUMN IF NOT EXISTS)
- ✅ Preserves all existing data
- ✅ Reversible (DROP COLUMN)
- ✅ Uses ON CONFLICT DO NOTHING for idempotency
