## Status

**PASS**

## Date

September 3, 2026

## Executive Summary

P1.33 audits Astrova's end-to-end user experience across all 13 frontend pages, shared components, map, chatbot, search, and data presentation. The audit identifies the highest-impact improvements needed to make Astrova feel like a polished, modern cultural-heritage product suitable for Smart India Hackathon demonstration.

**Overall Assessment:** Astrova is a functional, well-structured heritage platform with strong bones. The architecture is clean, the visual identity is consistent (terracotta palette), and the core user journey works. However, several UX issues prevent it from feeling truly polished:

1. **Branding inconsistency** — a blue CTA button on the homepage breaks the terracotta visual identity
2. **Stale data on AI page** — shows "52 Heritage Records" when actual count is 74
3. **Weak "wow moment"** — the homepage doesn't showcase heritage imagery prominently enough
4. **Map underutilized** — the map preview on the homepage is a static icon, not an actual map
5. **Search results lack context** — heritage search results don't show period or state consistently

## SIH Demonstration Audit

### 1. What makes Astrova memorable?
The **interactive map with 12 states** and the **6-language chatbot** are the most distinctive features. The terracotta visual identity is also distinctive.

### 2. What would a judge understand within 30 seconds?
- "Explore India's heritage" — clear from homepage hero
- Interactive map — immediately visible
- Multiple states — state cards show breadth

### 3. What feature demonstrates technical depth?
- Full-text search with relevance ranking
- Timeline with CTE-optimized queries
- Multilingual chatbot with intent detection
- JWT authentication with HttpOnly cookies
- In-memory rate limiting

### 4. What feature demonstrates cultural value?
- 74 heritage entities across 12 states
- 6 curated collections
- 9 historical periods
- 6 Indian languages supported

### 5. What feature demonstrates AI?
- Chatbot with intent detection (regex + ML)
- Language-aware knowledge retrieval
- Romanized input detection
- Context-aware suggestions

### 6. What feature demonstrates data engineering?
- 27 database migrations
- 15 tables
- Full-text search with relevance scoring
- Timeline CTE optimization

### 7. What feature demonstrates user experience?
- Search modal with keyboard navigation
- Interactive map with state filtering
- Favorites with localStorage sync
- Responsive design

### 8. What currently feels unfinished?
- The blue CTA button on the homepage
- "52 Heritage Records" on AI page (should be 74)
- No source citations visible to users
- Map preview on homepage is just an icon

### 9. What looks like a generic CRUD website?
- Heritage listing page in flat grid mode (without category grouping)
- Favorites page (just a grid of cards)

### 10. What should become the "wow moment"?
**The homepage hero should showcase a rotating carousel of stunning heritage images** — India's heritage is visual and the homepage should lead with imagery, not just text. Alternatively, the **map with all 74 heritage markers appearing** as you zoom into a state could be the wow moment.
