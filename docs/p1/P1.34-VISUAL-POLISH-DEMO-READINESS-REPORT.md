## Objective

Turn the currently functional Astrova experience into a visually polished, credible, memorable SIH-ready product by addressing the P1.33 audit findings.

## Starting State

- All core features working (search, heritage, collections, timeline, chatbot, auth, favorites)
- Homepage CTA using wrong color (blue)
- AI page showing hardcoded "52 Heritage Records"
- No heritage imagery on homepage hero
- Static map preview icon
- No source attribution on heritage detail pages
- Description duplication on heritage detail
- Related heritage without images
- No collection search in global search modal
- categoryIcons duplicated across 5+ files
- Chatbot returning text-only responses with broken action links

## Implemented Changes

### 1. Homepage CTA Color Fix
- **Problem**: "Explore Heritage" CTA used `#1a237e` (blue), breaking terracotta visual identity
- **Solution**: Changed to `bg-heritage-gold hover:bg-heritage-gold/90` matching existing design language
- **File**: `frontend/app/page.tsx`

### 2. Dynamic Statistics
- **Problem**: AI page showed hardcoded "52 Heritage Records" (actual: 74)
- **Solution**: Added `useApi<HeritageEntity[]>("/heritage")` and computed count dynamically with loading state
- **File**: `frontend/app/ai/page.tsx`

### 3. Homepage Hero Imagery
- **Problem**: Hero was text-only gradient with no heritage visual above the fold
- **Solution**: Added atmospheric heritage image background (`/assets/heritage/ajanta_caves.jpg`) with parallax scroll, warm glow accents, and heritage pattern overlay
- **File**: `frontend/app/page.tsx`

### 4. Homepage Map Preview
- **Problem**: "Interactive Map" section was a static icon
- **Solution**: Replaced with stylized India silhouette with animated heritage location dots and pulsing center marker
- **File**: `frontend/app/page.tsx`

### 5. Sources & References
- **Problem**: Heritage detail pages had source data but didn't display it
- **Solution**: Added "Sources & References" section with verification badges (Shield + CheckCircle), external links, and editorial styling
- **File**: `frontend/app/heritage/[id]/page.tsx`

### 6. Description Deduplication
- **Problem**: Hero and editorial section showed same description
- **Solution**: Hero shows truncated excerpt (first 150 chars + "..."), editorial section shows full story

### 7. Related Heritage with Images
- **Problem**: Related heritage items were text-only
- **Solution**: Added media images, hover effects, category badges, and state/location info to related heritage cards
- **File**: `frontend/app/heritage/[id]/page.tsx`

### 8. Collection Search
- **Problem**: Global search modal (Cmd+K) only searched heritage and states
- **Solution**: Added collection results fetched from `/api/collections`, filtered by name/description match
- **File**: `frontend/components/ui/SearchModal.tsx` (both SearchModal and SearchModalProvider)

### 9. Shared Category Constants
- **Problem**: `categoryIcons` was duplicated across 5+ files
- **Solution**: Created `frontend/constants/categories.ts` with `getCategoryIcon()`, `getCategoryColor()`, `getCategoryLabel()`, and `categoryColors` record
- **New file**: `frontend/constants/categories.ts`
- **Updated**: page.tsx (heritage, favorites, timeline, collections), heritage/[id]/page.tsx

### 10. Chatbot Heritage Result Cards
- **Problem**: Chatbot returned text-only responses with no visual heritage cards
- **Solution**: Backend now returns `heritage_results` array with entity metadata (name, slug, category, state, description). Frontend renders clickable heritage cards with icons, badges, and navigation links
- **Files**: `backend/src/services/chatbot.ts`, `backend/src/routes/ai.ts`, `frontend/components/ai/ChatBot.tsx`

### 11. Chatbot Action Link Fix (Bug Fix)
- **Problem**: `view_heritage` action used `chatbot_knowledge.id` as URL path, but heritage detail page expects `heritage_entities.slug`. Links were broken (404).
- **Solution**: Backend now looks up matching heritage entity by name and uses the correct slug for action links
- **File**: `backend/src/services/chatbot.ts`
