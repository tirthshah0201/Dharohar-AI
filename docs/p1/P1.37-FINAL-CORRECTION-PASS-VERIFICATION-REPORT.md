## 3. Bug Verification

### BUG-001 — Favorites treats authenticated user as unauthenticated

**Status: VERIFIED FIXED**

Root cause (from previous pass): `useFavorites` had independent auth check that desynchronized from shared `useAuth` context.

Fix: `useFavorites` accepts `sharedAuthenticated` and `isAuthLoading` from `useAuth`, eliminating the independent auth check.

**Runtime verification:**
- Register → login → /me → favorites list → add favorite → verify persisted → remove favorite → logout → /me returns 401
- Full flow: 10/10 tests passed ✅

### BUG-002 — Login rate limit blocks registration

**Status: VERIFIED FIXED**

Root cause (from previous pass): Global `authRateLimit` (10 req/15min) applied to ALL `/api/auth/*` routes.

Fix: Removed global `authRateLimit` from `index.ts`. Login has independent `loginRateLimit` (5/15min), Register has independent `registerRateLimit` (3/hour).

**Runtime verification:**
- 5 failed logins → login rate-limited → registration still succeeds → newly registered account works
- 2/2 tests passed ✅
