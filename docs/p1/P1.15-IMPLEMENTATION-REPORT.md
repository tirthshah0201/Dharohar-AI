## 3. Changes Implemented

### 3a. Search API — Filter Bug Fix + Sorting

**File:** `backend/src/routes/search.ts`

**Bug fixed:** The previous implementation used nested `SELECT * FROM (...) AS combined WHERE` for combining category/state/type filters, which caused SQL syntax errors when multiple filters were active simultaneously.

**Solution:** Rewrote to use a PostgreSQL CTE (Common Table Expression) that builds the combined result set once, then applies all filters on the outer query.

**New features:**
- `sort=relevance|name|state` parameter
- `order=asc|desc` parameter
- All filters (category, state, entity type) now correctly compose in a single WHERE clause
- Category filter works for both heritage (category column) and locations (type column aliased as category in CTE)

### 3b. Heritage Detail API — Period + Media

**File:** `backend/src/routes/heritage.ts`

**Changes:**
- Added `LEFT JOIN historical_periods hp ON he.period_id = hp.id` to detail query
- Returns `period` object with `id`, `name`, `start_year`, `end_year`, `description`
- Added media query to return all media records for the entity
- Returns `media` array sorted by `is_primary DESC, display_order ASC`

### 3c. Heritage Detail Page — Period Display + Media Gallery

**File:** `frontend/app/heritage/[id]/page.tsx`

**Changes:**
- Updated TypeScript interface to include `period` and `media` types
- "At a Glance" section now displays actual period name and date range (e.g., "Medieval Period — 700 CE — 1300 CE")
- Added "Gallery" section between "Explore the Place" and "Sources"
- Gallery handles single-image entities elegantly (no unnecessary gallery UI)
- Gallery handles multiple images with a 2-column grid (primary image spans full width)
- Hero section now prioritizes database media over frontend fallback images
- Image priority: database primary media → database image_url → frontend fallback mapping

### 3d. Heritage Listing Page — Sort Controls

**File:** `frontend/app/heritage/page.tsx`

**Changes:**
- Added `sortBy` state with options: Name A–Z, Name Z–A, State, Category
- Sort dropdown appears next to result count
- Sorting works with all existing filters (category, state, search)
- Clear filters button moved next to sort dropdown

### 3e. Explore Page — Search State Context

**File:** `frontend/app/explore/page.tsx`

**Changes:**
- Search API calls now include `&state=` parameter when a state is selected
- State filter applies to both location browsing and search results
