## Search

### Current Implementation

The search endpoint (`/api/search`) performs:
```sql
(heritage_entities: name ILIKE, description ILIKE)
UNION ALL
(locations: name ILIKE, description ILIKE)
```

Results include `slug` field (from P1.1).

### Status

- ✅ Slug included in search results
- ✅ parent_id semantic bug fixed (P1.1)
- ✅ Both heritage and locations searchable
- ⚠️ No fuzzy search (ILIKE only)
- ⚠️ No state/region filtering in search

## Chatbot

### Current Architecture

```
User message
    ↓
ML Intent Classification (v5)
    ↓ (fallback to regex)
State Detection
    ↓
Knowledge Retrieval (chatbot_knowledge)
    ↓
Response + Actions
```

### Entity Links

- chatbot_knowledge.heritage_entity_id → links to heritage_entities (42 of 58)
- Actions generate canonical URLs: `/heritage/{slug}` or `/explore/{slug}`
