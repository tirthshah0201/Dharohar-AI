- Sanchi Stupa ↔ Khajuraho Temples (ancient architecture)

### 2. Heritage Detail Page — Relationship Explorer

- Added relationship type badges (ASSOCIATED_WITH, PRACTICED_BY, etc.)
- Added editorial subtitle: "Discover connections across India's heritage traditions"
- Improved card layout with arrow navigation hint
- Better hover states and visual hierarchy

### 3. Heritage Listing Page — State Filtering

- Added state filter bar below category chips
- Unique states extracted dynamically from database
- Combined category + state + search filtering
- Improved result count with filter context
- Updated clear-all button to reset all filters

### 4. Explore Page — Search UX

- Added state filter indicator with clear button
- Added search result count display
- Improved empty state messaging
- Added state context and entity type badges to search results
- Distinguished heritage vs location results visually

### 5. Heritage API — Location Context + Deduplication

- Enhanced heritage list endpoint to return location info (id, name, state)
- Added `DISTINCT ON` to related heritage query to prevent duplicate entries
- Fixed duplicate key console error
