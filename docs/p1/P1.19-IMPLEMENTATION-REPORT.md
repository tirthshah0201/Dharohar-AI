## 3. Map Period Filtering

**Files modified:**
- `frontend/services/map/map-data.ts` — Added `period_id` to `MapHeritage` and `MapFeature` types
- `frontend/components/map/AstrovaMap.tsx` — Added period filter state, loads periods from `/api/periods`, filters markers by period
- `frontend/components/map/MapControls.tsx` — Added period filter tab with period list

**Behavior:**
- Map loads periods from `/api/periods` on mount
- Filter dropdown now has two tabs: Category and Period
- Selecting a period filters heritage markers to only show entities from that period
- Reset button clears all filters (state, category, period)
- Entities without period references are excluded when a specific period is selected

---

## 4. Map Popup Enhancement

**File:** `frontend/components/map/HeritagePopup.tsx`

**Changes:**
- Added `period` prop to display historical period name
- Shows period with clock icon in heritage-gold color
- Changed "Details" button text to "View Heritage" for clarity

**Popup now shows:**
- Heritage name
- Category
- State
- Historical period (when available)
- Ask Atlas button
- View Heritage link
