# P1.40 — Admin Media Upload: Video Support

## 1. Objective

Extend the existing Admin Media Upload system to support video uploads (MP4, WebM, MOV) in addition to images (JPG, PNG, WebP).

## 2. Existing Architecture

| Component | Technology |
|-----------|-----------|
| Frontend | Next.js 16.3.2 + React + TypeScript + Tailwind CSS |
| Backend | Express.js + Node.js + TypeScript |
| Database | Neon PostgreSQL |
| File Upload | multer (multipart/form-data) |
| Auth | JWT + HttpOnly cookies + RBAC |
| Storage | Local filesystem (`backend/uploads/heritage/`) |

## 5. Implementation Details

### Backend Upload Utility
- Added `ALLOWED_VIDEO_MIME_TYPES`: video/mp4, video/webm, video/quicktime
- Added `ALLOWED_VIDEO_EXTENSIONS`: .mp4, .webm, .mov
- Added `VIDEO_MAX_SIZE`: 50 MB
- Added `getMediaType()` function to determine type from MIME
- Added MIME/extension consistency check
- Separate size limits for images (5 MB) and videos (50 MB)

### Admin Route
- Replaced manual MIME detection with `getMediaType()` function
- Now correctly detects video type from MIME

### Admin UI
- Updated file input `accept` attribute for video types
- Updated frontend validation for video types and size limits
- Auto-sets media type based on selected file MIME
- Added video preview using `<video>` element
- Updated label text to "Upload Media" instead of "Upload Image"

### Heritage Detail Page
- Gallery section now renders `<video>` for video media items
- Hero section already supported video (unchanged)

### GalleryLightbox
- Main display: Renders `<video>` for video type, `<img>` for images
- Thumbnails: Renders `<video>` for video type, `<img>` for images

## 6. Database

**No migration required.** The existing `media` table already supports `type = 'video'`:
```sql
type VARCHAR(50) NOT NULL CHECK (type IN ('image', 'document', 'audio', 'video'))
```
