### BUG-007 (P3→security-relevant) — Admin user safety
- `GET /api/admin/users`: strict query-param allowlist (`q`, `limit`) — unknown params (e.g. `search`) now rejected with 400 listing allowed params, instead of silently returning ALL users. Listing capped (default 200, max 500).

Response includes deleted user id + favorites_removed count. No bulk endpoint exists. Verified end-to-end including that confirmed single-user delete still works and cleanup of test users used exactly this path.
