## Executive Summary

## Backend Changes

### New Route: `backend/src/routes/collections.ts`

| Endpoint | Method | Description |
|----------|--------|-------------|
| `GET /api/collections` | GET | List all active collections with entity counts and hero media |
| `GET /api/collections/:slug` | GET | Get collection detail with heritage entities |

**Registration:** Added to `backend/src/index.ts` at `/api/collections`

**Features:**
- Entity counts calculated from database
- Hero images from primary media
- Entity detail includes period, location, media
- Sorted by display_order
- Parameterized SQL
- X-API-Key authentication

## AI/Discovery Changes

The existing chatbot (`backend/src/services/chatbot.ts`) was already sophisticated with:
- 6-language support (en, gu, hi, mr, ta, pa)
- ML-based intent detection with regex fallback
- Language-aware knowledge retrieval with English fallback
- State-aware exploration
- Structured actions (view_heritage, view_map, view_timeline, explore_state, explore_category)
- Geocoding via OpenStreetMap

**No chatbot changes were required** — the existing architecture already supports the discovery needs. The collections system provides the curated discovery path that was missing.
