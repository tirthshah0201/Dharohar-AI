## Implementation Details

### 1. Marathi/Tamil/Punjabi Knowledge

**File:** `database/migrations/024_p1_multilingual_search.sql`

| Language | Entries | Entities Covered |
|----------|---------|-----------------|
| Marathi (mr) | 6 | Ajanta Caves, Ellora Caves, Rani ki Vav, Golden Temple, Sabarmati Ashram, Red Fort |
| Tamil (ta) | 6 | Meenakshi Amman Temple, Bharatanatyam, Rani ki Vav, Golden Temple, Warli Art, Navratri |
| Punjabi (pa) | 5 | Golden Temple, Jallianwala Bagh, Phulkari, Rani ki Vav, Sabarmati Ashram |

Each entry includes:
- Culturally appropriate descriptions in the target language
- Significance text
- Keywords for matching
- Romanized/transliterated question examples for chatbot matching
- Valid heritage_entity_id references

### 2. Search Suggestions Endpoint

**File:** `backend/src/routes/search.ts`

Added `GET /api/search/suggestions?q=<query>`:
- Returns heritage names, states, periods, and categories matching the query
- Deduplicates results
- Returns max 8 suggestions
- Handles empty/short queries gracefully
- Uses parameterized SQL (safe against injection)
- Ordered: heritage → states → periods → categories
