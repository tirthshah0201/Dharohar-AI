### Migration 006: `006_p1_chatbot_bridge.sql`

**Purpose:** Link chatbot_knowledge to heritage_entities and locations

**Schema Changes:**
```sql
-- New nullable FK columns
chatbot_knowledge.heritage_entity_id UUID REFERENCES heritage_entities(id)
chatbot_knowledge.location_id UUID REFERENCES locations(id)

-- New indexes
idx_knowledge_heritage_entity ON chatbot_knowledge(heritage_entity_id)
idx_knowledge_location ON chatbot_knowledge(location_id)
```

**Data Changes:**
- Populates heritage_entity_id for exact name matches (31 of 58 records)
- Populates location_id from matched heritage_entities
- Populates location_id from state-level location matches
