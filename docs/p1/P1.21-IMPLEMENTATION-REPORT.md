### 3. Multilingual Readiness

**File:** `database/migrations/021_p1_chatbot_multilingual.sql`

Added `language` column to `chatbot_knowledge` table:
- Default value: 'en' (English)
- NOT NULL constraint
- Index on language column
- Unique index on (heritage_entity_id, language) for future multilingual knowledge expansion
- All 75 existing records set to language='en'

This enables future expansion to Gujarati, Hindi, Marathi, Tamil, and Punjabi knowledge entries without schema changes.
