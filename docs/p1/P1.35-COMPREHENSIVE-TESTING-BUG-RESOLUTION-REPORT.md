## Bugs Discovered

### BUG-001: Heritage Detail Missing Location Data (Critical)

**Module**: Heritage Detail API
**Severity**: Critical
**Symptom**: All heritage detail pages showed `location: None` — no state, no coordinates, no location name
**Root Cause**: The `GET /api/heritage/:id` route was missing `LEFT JOIN locations l ON he.location_id = l.id` in both the UUID and slug query paths. The list endpoint had the join, but the detail endpoint didn't.
**Impact**: 
- Heritage detail pages had no location info
- "Explore the Place" map section was completely empty
- "Ask Astrova" link from heritage detail couldn't include state context
- Coordinates were missing for map display
**Fix**: Added `LEFT JOIN locations l ON he.location_id = l.id` to both UUID and slug query paths, and added `l.id, l.name, l.slug, l.type, l.latitude, l.longitude, l.state` to the JSON build.
**Files**: `backend/src/routes/heritage.ts`
**Verification**: PASS — Adalaj Stepwell now shows "Gujarat, Gujarat" with coordinates; entities without locations correctly return `null`

### BUG-002: Chatbot State Exploration Heritage Cards Empty (High)

**Module**: Chatbot Service
**Severity**: High
**Symptom**: Chatbot queries like "tell me about Gujarat" returned heritage text but 0 heritage cards, and `knowledge_ids` contained `[None, None, None, ...]`
**Root Cause**: The `getStateOverview()` SQL query was missing the `id` field in its SELECT clause: `SELECT heritage_name, heritage_type, city, ...` instead of `SELECT id, heritage_name, heritage_type, city, ...`
**Impact**:
- Heritage cards couldn't render for state exploration queries
- `knowledge_ids` were all `null`
- Chatbot action links for state queries were broken
**Fix**: Added `id` to the SELECT clause in `getStateOverview()`
**Files**: `backend/src/services/chatbot.ts`
**Verification**: PASS — "tell me about Gujarat" now returns 5 heritage cards with valid IDs

### BUG-003: "Rani ki Vav" Intent Detection Failure (Medium)

**Module**: Chatbot Intent Detection
**Severity**: Medium
**Symptom**: "what is Rani ki Vav" returned `intent: unknown` instead of `heritage_information`
**Root Cause**: The intent detector's heritage keyword list included "stepwell" but not "vav" (Gujarati for stepwell). "Rani ki Vav" is one of India's most famous stepwells but the keyword pattern didn't recognize it.
**Impact**:
- Users asking about Rani ki Vav got generic "unknown" responses
- Heritage search didn't trigger for this query
**Fix**: Added `vav`, `ni vav`, `ki vav` to the heritage keyword pattern
**Files**: `backend/src/services/chatbot.ts`
**Verification**: PASS — "what is Rani ki Vav" now returns `intent: heritage_information` with 3 heritage cards
