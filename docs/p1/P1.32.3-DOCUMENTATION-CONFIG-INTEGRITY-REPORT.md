## API Key Security

- `DEMO_API_KEY` is server-side only — consumed by Next.js proxy route
- Proxy attaches `X-API-Key` header when forwarding to Express
- Browser never receives the key
- Fail-safe: if `DEMO_API_KEY` not configured, all data endpoints return 401
- ⚠️ Local `.env` has `DEMO_API_KEY` set to a Neon REST URL — should be randomized for production

## CORS Verification

From source code (`backend/src/index.ts`):

```typescript
origin: process.env.NODE_ENV === "production"
  ? (origin, callback) => {
      if (!origin || ALLOWED_ORIGINS.includes(origin)) {
        callback(null, true);
      } else {
        callback(new Error("Not allowed by CORS"));
      }
    }
  : true,
```

| NODE_ENV | Behavior |
|----------|----------|
| `production` | Origins checked against `ALLOWED_ORIGINS`; no-origin allowed |
| `development` or missing | All origins allowed (`true`) |

**Deployment requirement:** `NODE_ENV=production` must be explicitly set.
