## 8. Remaining Limitations

1. **In-memory rate limiting** — single-server only, resets on restart
2. **No pagination** — works for 74 entities but not scalable
3. **No structured logging** — console.log only
4. **No CI/CD pipeline** — manual builds and deploys
5. **No password reset** — users cannot recover accounts
6. **No email verification** — accounts not verified
7. **No refresh tokens** — JWT is stateless with 7-day expiry
8. **DEMO_API_KEY not randomized** — currently set to Neon REST URL in .env
9. **Browser verification unavailable** — testing environment limitation
