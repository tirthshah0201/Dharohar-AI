2. **Laptop Mockup:** Website screenshot embedded as image. The mockup frame is created with shapes (rounded rectangles) rather than a photographic laptop frame. This is editable but less photorealistic.

3. **Preview Images:** Generated using Pillow rendering of shapes (not true PPTX-to-image conversion). For exact visual preview, open the PPTX in PowerPoint or Google Slides.

4. **No Animations:** Presentation is static. For SIH final round, this is appropriate as judges focus on content clarity over animation effects.
